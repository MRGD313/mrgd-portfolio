# وب‌سایت شخصی دکتر محمدرضا گنج‌دانش — drganjedanesh.ir

وب‌سایت رزومه شخصی، فارسی (RTL)، تک‌صفحه‌ای و استاتیک؛ آماده برای انتشار روی **GitHub Pages** و دامنه **drganjedanesh.ir**.

## ساختار پروژه

```
├── index.html              ← صفحه اصلی (سرصفحه/متا/سئو)
├── assets/
│   ├── css/style.css       ← طراحی (پالت، تایپوگرافی، چیدمان)
│   ├── js/content.js       ← ★ تمام محتوای رزومه — فایل ویرایش محتوا
│   ├── js/main.js          ← منطق نمایش (رندر بخش‌ها، ناوبری)
│   ├── fonts/              ← فونت وزیرمتن (مجوز OFL — self-hosted)
│   └── icons/              ← فاوآیکون (SVG و PNG)
├── public/images/
│   ├── profile.jpg         ← عکس پرتره (600×750)
│   └── og-card.png         ← کارت پیش‌نمایش اشتراک‌گذاری (1200×630)
├── CNAME                   ← دامنه drganjedanesh.ir
├── robots.txt
├── sitemap.xml
└── .github/workflows/deploy.yml  ← انتشار خودکار با GitHub Actions
```

## ویرایش محتوای رزومه در آینده

**فقط فایل `assets/js/content.js` را ویرایش کنید** (داخل هر بخش با توضیح فارسی مشخص است):

- `about` — پاراگراف‌های «درباره من»
- `experience` — تجربه‌های کاری (عنوان، سازمان، بازه، نوع همکاری، توضیح)
- `education` — تحصیلات
- `certifications` — گواهی‌نامه‌ها
- `honors` — افتخارات و جوایز
- `research` — مقالات
- `skills` — مهارت‌ها
- `contact` — راه‌های ارتباطی (به ترتیب اولویت)

هر بخشی که خالی ( `[]` ) باشد، از صفحه حذف می‌شود. عنوان حرفه‌ای، شعار و راه‌های بالای صفحه (Hero) در `index.html` (جستجو برای `hero-title` و `hero-tagline`) قرار دارند. پس از ویرایش، یک commit و push جدید بزنید؛ سایت خودکار به‌روزرسانی می‌شود.

## انتشار با GitHub Pages

انتشار از طریق **GitHub Actions** انجام می‌شود (`.github/workflows/deploy.yml`):

1. مخزنی با این محتوا بسازید (پیشنهادی: `MRGD313/mrgd-portfolio`).
2. در Settings → Pages، گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
3. هر push به شاخهٔ `main` باعث build و انتشار خودکار می‌شود.
4. فایل `CNAME` باعث ثبت خودکار دامنه `drganjedanesh.ir` در Pages می‌شود.

## تنظیم DNS برای دامنه (در پنل ثبت‌کنندهٔ دامنه)

> مقادیر رسمی بر اساس مستندات GitHub. پس از فعال شدن DNS، بررسی می‌کنیم که واقعاً متصل شده است.

**دامنه اصلی `drganjedanesh.ir`** — چهار رکورد A (یا در صورت پشتیبانی، ALIAS/ANAME به `MRGD313.github.io`):

| نوع | نام | مقدار |
|-----|-----|-------|
| A | @ | `185.199.108.153` |
| A | @ | `185.199.109.153` |
| A | @ | `185.199.110.153` |
| A | @ | `185.199.111.153` |

در صورت پشتیبانی IPv6 (اختیاری، مکمل A):

| نوع | نام | مقدار |
|-----|-----|-------|
| AAAA | @ | `2606:50c0:8000::153` |
| AAAA | @ | `2606:50c0:8001::153` |
| AAAA | @ | `2606:50c0:8002::153` |
| AAAA | @ | `2606:50c0:8003::153` |

**دامنهٔ جایگزین `www.drganjedanesh.ir`:**

| نوع | نام | مقدار |
|-----|-----|-------|
| CNAME | www | `MRGD313.github.io` |

با این تنظیم، `www.drganjedanesh.ir` خودکار به `drganjedanesh.ir` هدایت (redirect) می‌شود. توصیه می‌شود ابتدا دامنه را در اکانت GitHub (Settings → Pages → وریفای) **تأیید مالکیت** کنید. پس از اعمال DNS (تا ۲۴ ساعت)، گزینهٔ **Enforce HTTPS** را در Settings → Pages فعال کنید.
