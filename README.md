# وب‌سایت شخصی محمدرضا گنج دانش — drganjedanesh.ir

وب‌سایت تک‌صفحه‌ای فارسی (RTL) با HTML5، CSS3 و JavaScript خالص — بدون فریم‌ورک و بدون مرحله Build.
مناسب انتشار رایگان روی **GitHub Pages** و اتصال به دامنهٔ **drganjedanesh.ir**.

## ساختار پروژه

```
├── index.html               ← صفحه اصلی
├── 404.html                 ← صفحه خطای ۴۰۴
├── assets/
│   ├── css/style.css        ← طراحی (توکن‌های رنگ، چیدمان، واکنش‌گرایی)
│   ├── js/main.js           ← منوی موبایل، لینک فعال، Fade-in، فالبک آیکون‌ها
│   ├── img/                 ← تصاویر (خودتان آپلود می‌کنید)
│   │   ├── profile.jpg
│   │   ├── bale-icon.svg
│   │   ├── paziresh24-icon.jpg
│   │   └── og-card.png
│   ├── icons/               ← فاوآیکون
│   └── resume.pdf           ← فایل رزومه (خودتان آپلود می‌کنید)
├── CNAME                    ← drganjedanesh.ir
├── robots.txt
├── sitemap.xml
└── .github/workflows/deploy.yml  ← انتشار خودکار
```

> **فایل‌هایی که باید خودتان آپلود کنید** (کدها به آن‌ها اشاره می‌کنند و تا آپلود نشوند صفحه سالم می‌ماند):
> - `assets/img/profile.jpg` — عکس پروفایل (ترجیحاً مربع، حداقل ۶۰۰×۶۰۰)
> - `assets/img/bale-icon.svg` — آیکون پیام‌رسان بله (همین حالا اضافه شده است)
> - `assets/img/paziresh24-icon.jpg` — آیکون پذیرش۲۴ (همین حالا اضافه شده است)
> - `assets/resume.pdf` — فایل رزومه

اگر عکس پروفایل یا آیکون‌ها موجود نباشند، سایت به‌جای آیکون شکسته، جایگزین متنی/SVG نشان می‌دهد؛ پس انتشار بدون آن‌ها هم ایمن است.

## ویرایش محتوا

- متن‌ها، لینک‌ها و بخش‌ها همه در `index.html` هستند (کامنت‌گذاری‌شده و قابل ویرایش).
- رنگ‌ها، فاصله‌ها و اندازه‌ها در ابتدای `assets/css/style.css` به‌صورت «توکن» تعریف شده‌اند.
- برای تغییر شماره تلگرام/بله، مقدارهای `@MRGD_12` و لینک‌ها را در بخش «راه ارتباطی» عوض کنید.

## انتشار روی GitHub Pages

1. مخزن: `MRGD313/mrgd-portfolio` (شاخهٔ `main`).
2. هر push به `main` با GitHub Actions به‌صورت خودکار منتشر می‌شود.
3. در **Settings → Pages**، گزینهٔ Source باید روی **GitHub Actions** باشد.
4. فایل `CNAME` دامنه را روی `drganjedanesh.ir` تنظیم می‌کند.

## دامنه و DNS (خلاصه)

- **DNS** روی Cloudflare (نِیم‌سرورهای `alice.ns.cloudflare.com` و `sid.ns.cloudflare.com`).
- رکوردهای لازم:
  - `A @` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
  - `CNAME www` → `MRGD313.github.io`
- حالت هر رکورد: **DNS only** (ابر خاکستری). پروکسی Cloudflare برای صدور گواهی HTTPS گیت‌هاب باید خاموش بماند.
- پس از آمادهٔ شدن گواهی، **Enforce HTTPS** را در Settings → Pages فعال کنید.

## پیش‌نمایش محلی

کافی است `index.html` را در مرورگر باز کنید یا یک سرور استاتیک ساده اجرا کنید:

```bash
npx serve .
```
